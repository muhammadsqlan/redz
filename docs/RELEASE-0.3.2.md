# ReDZ 0.3.2

First public release of ReDZ — Read Easy, previously named ReadAlong.

- Native Mac reader for EPUB and selectable-text PDF.
- Offline Kokoro voices, sentence highlighting, and 0.75×–2× playback.
- Original PDF view, zoomable figures, and EPUB export.
- Apple Silicon, macOS 14 or later.

Open the disk image, drag ReDZ into Applications, and open ReDZ.

PDF limits: 300 pages / 150 MB. OCR is not included; image-only content, tables, and displayed equations are not narrated.

Application source is AGPL-3.0-or-later. Dependency source, license notices, and SHA-256 checksums accompany this release.
